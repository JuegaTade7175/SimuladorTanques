# Recursos de desarrollo

Los archivos editables durante el desarrollo van aquí. La carpeta `Dist/recursos`
se conserva como copia preparada para la distribución portátil.

- `opciones.cfg`, `balistica.properties`, `misiones.xml` y `datos_tanque.json`
- `tanques/`, `mapas/`, `audio/` y `shaders/`

Se mantiene el nombre `recursos` para coincidir con el proyecto. Cuando se configure
el cargador de recursos de jMonkeyEngine, esta carpeta se podrá marcar como raíz de
recursos en IntelliJ.
